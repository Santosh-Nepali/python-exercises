# "Sort Fast, Sort True"

## 1. Game Concept

I have been living in HOAS appartment. We have been getting email from HOAS atleast 3-4 emails about improper sorting of garbage into the bins. When I am starting thinking of game design as a project based on SDG(Sustainable Development Goal), HOAS emails give me motivation about "Sort Fast, Sort True'. Therefore, it is an educational and interactive game designed to raise awareness about waste management, recycling and environmental sustainability. The game is based on sorting different types of waste into their corresponding recycling bins, such as Bio, Paper, Energy, Plastic and Mixed Waste,

The main idea is to make learning about waste separation fun, engaging, and accessible. Through interactive gameplay, players develop a better understanding of how to dispose of waste correctly and how everyday actions can contribute to protecting the environment.

## 2. Game Objective

The primary objective of the game is to teach players how to identify, classify, and sort waste materials into the correct recycling bins.

The specific objectives are to:

- Improve players' knowledge of different waste categories and recycling practices.
- Encourage responsible waste disposal habits.
- Develop decision-making and problem-solving skills through interactive challenges.
- Increase awareness of the environmental consequences of improper waste management.

Players aim to sort as many waste items as possible into the correct bins, earn points for accurate sorting, and achieve a high score while minimising mistakes.

## 3. Game Operating Principles & functionalities

The game operates through a simple text based interactive sorting mechanism that allows players to identify waste items and place them in the appropriate bins.
The basic operating principles are :
a) Players stands at collection point where different waste items such as plastic bottles, newspapers, food scrabs etc are selecting using command "TAKE". This command update the list inventory list of waste items where user carry to the correspodnign bins

b) In order to travel to the waste bins, players use command "MOVE" towards the desired waste bins. "Move" command displays the list of bins and players choose among them.

c) After Selection the bins, players use the command "DROP" to release the selected item into the corresponding bin. There are two consiquences of this action. - Players are rewarded +1 point for correct sorting of waste item. - Player's score is reduced by 1 for incorrect sorting of the waste item and
also given why the sorting of waste items is not correct. This immediate feedback of wrong action increase the players knowledge about of waste items.

d) Players check their score using command "SCORE", players information using
"USER-PROFILE" and also exit the game using command LOPETA.

e) Similarly, player also user command "HELP" to have instructions to play the
game.

Motivate players to adopt sustainable behaviours in their daily lives.
Anyone can play this game. Garbage keeps arriving at the collection point and needed to be sorted correctly. The player picks up whatever has arrived, carries it to the correct bin and sorts it. The correct sorting earns a point and incorrect sorting loses a point but reveals the correct bin and a short explanation.

## 4. Sustainable Development Perspective

The central aspect of this game is Sustainable Development Perspective. The game supports environmental education by encouring responsible consumption, proper waste separation and resources conservation.

## 5. Conclusion

"Sort Fast Sort Right" Game combines education and entertainment to promote environmental awareness and sustainable behaviour. Through interactive sorting bins, immediate feedback, scoring, and educational content, players learn how to manage waste responsibly while developing practical recycling skills.

By integrating environmental, social, and economic sustainability into its design, the game aims not only to improve players' knowledge of recycling but also to encourage them to apply what they learn in their everyday lives.
